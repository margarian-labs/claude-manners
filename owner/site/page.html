Join in three steps

You need Windows, Git for Windows (Git Bash), Node 18 or newer and Claude Code. No GitHub account is needed.

  1. Clone the repo anywhere

    git clone https://github.com/margarian-labs/claude-setup.git

  2. Open Claude Code in the clone

    Say Follow START.md. Your agent installs the sync skill and walks you through the rest.

  3. Answer for each part

    Your agent checks your PC, backs up your current setup and asks about each part on its own.
