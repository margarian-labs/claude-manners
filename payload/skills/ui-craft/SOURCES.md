# Sources

Written for this setup on 2026-11-20 by condensing and rewording rules from:

- **unslop** by Damir Sokolovsky (@heydamir), https://github.com/heydamir/unslop, commit 620163e, CC BY 4.0. Most of sections 1-10 and `references/tokens.md` are adapted from its SKILL.md and references (signs, tokens). Changes: condensed, reworded, framework-neutral, React/Tailwind specifics and image tooling removed.
- **frontend-design** by Anthropic, https://github.com/anthropics/skills, commit e4bb5d9, Apache-2.0. Ideas: grounding in the subject, the default-look critique, motion only with a purpose, action names that stay the same through a flow.
- **Taste** by Leonxlnx, https://github.com/Leonxlnx/taste-skill, commit f6b7657, MIT. Ideas: two box levels at most, one filled button per view, form recipe, no auto-moving UI.

No code, scripts or assets from these projects are included.
