# Sources

- **Taste** by Leonxlnx, https://github.com/Leonxlnx/taste-skill, commit f6b7657, MIT. The hype, dead-phrase and virtue word lists (from `scripts/copy-lint.mjs`, as data), "facts not synonyms", the rival test.
- **Caveman** by Julius Brussee, https://github.com/JuliusBrussee/caveman, commit a192894, Apache-2.0. The one-line code review comment format.

No code or scripts from these projects are included.
