# claude-setup rules: messages to teammates

Installed by claude-setup into ~/.claude/rules/ and loaded every session. Sync manages this file: if you edit it, sync keeps your edit and asks before any update.

## Messages I send to colleagues: very short and casual

When I ask for a message to send a teammate (chat, Teams, Telegram), draft it **very, very short** (a few lines: what I need from them, links, why now) in casual {{TEAMMATE_LANGUAGE}}. Technical names, PR and ticket keys, file names and commands stay as they are. No formal greetings or sign-offs, and no emojis. Applies in every project, unless I ask for another language or tone.
